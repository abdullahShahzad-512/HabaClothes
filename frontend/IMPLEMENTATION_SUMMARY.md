## 💡 Customization Examples

### Faster Animations
```tsx
transition={{ duration: 0.4 }} // instead of 0.8
```

### Slower Animations
```tsx
transition={{ duration: 1.2 }} // instead of 0.8
```

### Stronger Scale Effect
```tsx
whileHover={{ scale: 1.15 }} // instead of 1.05
```

### More Stagger
```tsx
transition={{ staggerChildren: 0.2 }} // instead of 0.1
```
